# Module 5: Project Structure & Course Timeline

Imagine you are finalizing your paper's figures. Your main folder is filled with 15 different versions of your script, 10 intermediate CSV files, and dozens of plot images. In the clutter, you accidentally overwrite your raw sequencing spreadsheet with a modified version. Your original data is lost, and your entire analysis is compromised.

This is why a **Standardized Project Structure** is vital. By dividing your folders into dedicated slots for raw data, code, and outputs, you ensure safety and clarity. In this chapter, we will learn how to organize directories, use the **`here`** package to avoid broken file paths, and map out our 2-week course timeline.

---

## 1. Standard Project Folders

When you start a new analysis project, create a main folder and divide it into these simple subfolders:

```
my_project/
├── data/            # Where you store spreadsheets and data
│   ├── raw/         # Raw data (never edit these files!)
│   └── processed/   # Cleaned data saved by your code
├── code/            # Where you keep your R scripts
└── output/          # Where R saves your finished plots and tables
```

### Why do this?
*   **Safety**: Keeping your raw data in a read-only folder (`data/raw/`) prevents you from accidentally deleting or typing over your original experimental numbers.
*   **Cleanliness**: Plots are generated by code, so they go into a separate folder (`output/`) instead of cluttering your working space.

## 2. Handling File Paths: The `here` Package

A **file path** is the address of a file on your computer. 

If a collaborator opens your code, paths like this will fail because their computer username is different:
```R
# BAD: This path only works on your personal computer!
my_data <- read.csv("/home/mashxp/Documents/Bioinformatics/Spacial_Transcriptomics_Course/data/raw/data.csv")
```

To fix this, we use the **`here`** package. It automatically finds the main project folder, making your code work on anyone's computer.

```R
library(here)

# GOOD: This works on any computer!
# R will look inside: my_project -> data -> raw -> data.csv
file_path <- here("data", "raw", "data.csv")
my_data <- read.csv(file_path)
```
